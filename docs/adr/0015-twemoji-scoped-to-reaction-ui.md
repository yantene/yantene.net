# 0015. Twemoji はリアクションの UI にだけ当て、ページ全体には当てない

- Status: Accepted
- Date: 2026-08-12
- Deciders: @yantene

## Context / 背景

[ADR 0012](0012-emoji-reactions-with-twemoji.md) で、リアクションの意匠に Twemoji の COLR
フォントを self-host すると決めた。そのとき、フォントをページ全体のフォントスタックの先頭に
置いた。記事本文に書かれた絵文字も同じ意匠に揃えたかったためで、`unicode-range` が付いて
いるので「絵文字のコードポイントだけを受け持ち、日本語や英数字は後ろの指定に落ちる」と
考えていた。

**この前提が誤りだった。** 上流の `@font-face` の `unicode-range` には、キーキャップ絵文字
(`1️⃣` = U+0031 U+FE0F U+20E3) を組むために ASCII が含まれている。

```css
unicode-range: U+23, U+2A, U+30-39, U+200D, ...;
```

`U+30-39` は ASCII の数字そのものである。フォントスタックの先頭に置いた結果、本文に書かれた
素の数字までこのフォントに解決され、Twemoji が素の数字グリフを持たないため、**サイト中の
数字が画面から消えた** ([#180](https://github.com/yantene/yantene.net/issues/180))。日付も
記事番号も型番も金額も、字だけが無くなる。例外も警告も出ないので、見て気づくまで分からない。

## 検討した選択肢

- **案 A: 範囲から ASCII を外した `@font-face` を自前で宣言し、ページ全体への適用は続ける**
  - Pros: 記事本文の絵文字も Twemoji のまま。差分が小さい。
  - Cons: キーキャップ絵文字 12 個 (`0️⃣`〜`9️⃣` `#️⃣` `*️⃣`) が組めなくなる。**上流の範囲を
    こちらで書き写して持つことになり**、フォントを上げるたびに追随が要る。ページ全体に
    効かせる形自体は残るので、次に別の ASCII (`#` や `*`) で同じことが起きうる。
- **案 B: 適用先をリアクションの UI に絞り、ページ全体のフォントスタックからは外す**
  - Pros: そもそもこのフォントを入れた目的はリアクションの意匠だった。当てる先を
    「中身が絵文字しかない要素」に限れば、範囲に何が入っていても本文の字を巻き込まない。
    上流の CSS をそのまま読める。
  - Cons: 記事本文に書かれた絵文字は環境のフォントで出る (意匠が閲覧環境ごとにばらつく)。

## 決定

**案 B を採る。** ページ全体のフォントスタックから Twemoji を外し、リアクションの絵文字が
入る要素 (`.reaction-chip-emoji` / `.emoji-palette-item`) にだけ当てる。

決め手は、**当てる先を絞るほうが `unicode-range` の中身に依存しなくなる**こと。案 A は
今回見つかった 3 つを外すだけで、上流が別の ASCII を足せばまた同じ壊れ方をする。フォントを
入れた動機はリアクションの意匠なので、そこに閉じるのが素直でもある。

押された数 (`.reaction-chip-count`) は絵文字とは別の要素になっている。当てる先をこの粒度で
選べるのは、そのマークアップのおかげである。**絵文字と数字を同じ要素に入れないこと。**

## 帰結 / Consequences

- 良い面: 本文の数字が正しく出る。上流の `unicode-range` に何が入っていても本文に影響しない
  ため、フォントの更新で同じ壊れ方をしない。パッケージが配る CSS をそのまま読める。
- 悪い面・トレードオフ: **記事本文に書かれた絵文字は Twemoji にならない**。ADR 0012 が
  案 F の利点に挙げていた「記事本文の絵文字も同じ意匠に揃う」は取り下げる。閲覧環境の
  絵文字フォントで出るので、見え方は環境ごとに違う。
- 検証方法 / 今後の宣言: `app/frontend/twemoji.test.ts` が (1) `html` のフォントスタックに
  Twemoji が入っていないこと、(2) Twemoji を当てている CSS 規則のセレクタが絵文字だけの
  要素に限られていることを固定する。**リアクション以外の場所で絵文字の意匠を揃えたく
  なったときも、フォントスタックの先頭に戻してはならない。** 対象の要素を増やすこと。
